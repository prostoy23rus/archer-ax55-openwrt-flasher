## 🌟 Почему этот проект уникален

До сегодняшнего дня практически все инструкции по установке OpenWrt на роутеры TP-Link серии AX (включая Archer AX55 v1) начинались со слов:  
> *«Разберите роутер, подпаяйте провода к контактам UART (TX/RX/GND) на системной плате, подключите USB-TTL адаптер, прервите загрузку в U-Boot...»*

Стоковая прошивка TP-Link строго блокирует установку сторонних прошивок через заводской веб-интерфейс: проверяется бинарный заголовок **TP-Link Safeloader**, тип раздела и зашитая контрольная сумма **MD5 с секретной солью**.

**Этот проект решает проблему на 100% программно:**
* ❌ Никакого вскрытия корпуса и царапин.
* ❌ Никакого паяльника и риска спалить процессор статикой.
* ✅ Роутер обновляется прямо через штатное меню браузера промежуточным файлом-отмычкой.
* ✅ Встроенная программа-прошивальщик автоматически разворачивает OpenWrt без необходимости вручную вводить десятки сложных команд в терминале.

## 🔬 Аппаратная платформа (Hardware)

* **Модель:** TP-Link Archer AX55 (Hardware Version: **v1.0 / v1.20**)
* **Центральный процессор (SoC):** Qualcomm IPQ5018 (2 ядра Cortex-A53 @ 1.0 GHz)
* **Оперативная память (RAM):** 512 MB DDR3L
* **Флеш-память (NAND):** 128 MB SPI NAND (ESMT / Winbond)
* **Wi-Fi 2.4 GHz:** Встроенный в SoC (IPQ5018, 802.11b/g/n/ax 2x2 MIMO)
* **Wi-Fi 5 GHz:** Qualcomm QCN6122 (802.11a/n/ac/ax 2x2 MIMO, полоса 160 МГц, до 2402 Мбит/с)
* **Сетевой коммутатор (Switch):** Realtek RTL8367S (5x 1Gbps портов, подключен к SoC по шине HSGMII 2.5 Gbps)

## 🧠 Как это работает под капотом

Процесс состоит из трёх выверенных фаз:

```
[Стоковая прошивка TP-Link]
           │
           ▼ (Штатное обновление через Web UI: ax55v1_telnet_factory.bin)
[Заводская ОС с открытым портом Telnet (23)]
           │
           ▼ (Команды U-Boot: tp_boot_idx=0, config_name=config@mp03.3)
           ▼ (Запись factory.ubi в раздел rootfs / mtd11)
[OpenWrt Initramfs (ОЗУ / 192.168.1.1)]
           │
           ▼ (Команда sysupgrade -n /tmp/sysupgrade.bin)
[Чистая постоянная OpenWrt в NAND-памяти]
```

### 1. Обход проверки цифровой подписи (TP-Link Safeloader MD5 Salt)
TP-Link проверяет целостность файла прошивки по специальному алгоритму:
```python
# Секретная соль TP-Link Safeloader для Archer AX55
MD5_SALT = bytes([
    0x7a, 0x2b, 0x15, 0xed,
    0x9b, 0x98, 0x59, 0x6d,
    0xe5, 0x04, 0xab, 0x44,
    0xac, 0x2a, 0x9f, 0x4e,
])

payload = firmware_data[0x14:] # Данные после заголовка длины и MD5
calc_md5 = hashlib.md5(MD5_SALT + payload).digest()
firmware_data[0x04:0x14] = calc_md5
```
Кроме того, в заголовке раздела по смещению `0x1C` (28 байт) прописывается сигнатура `Pr` (Production вместо заблокированного `Cl` Cloud). После этого заводской веб-интерфейс принимает файл как оригинальное обновление.

### 2. Активация Telnet-демона
В заводской файловой системе Squashfs в файл `/etc/rc.local` внедряется автозапуск:
```sh
telnetd -l /bin/sh &
sleep 5 && iptables -I INPUT -p tcp --dport 23 -j ACCEPT &
```
После перезагрузки на роутере открывается полноценный Root Telnet shell на порту 23 без пароля.

## 🚀 Быстрый старт (Инструкция для новичков)

### Что понадобится:
1. Роутер **TP-Link Archer AX55 v1**.
2. Компьютер или ноутбук с Windows и сетевым кабелем (Ethernet).
3. Установленный **Python 3** (стандартный из Microsoft Store или python.org).

---

### Шаг 1: Загрузка файлов
1. Скачайте архив этого репозитория или склонируйте его:
   ```bash
   git clone https://github.com/prostoy23rus/archer-ax55-openwrt-flasher.git
   cd archer-ax55-openwrt-flasher
   ```
2. Скачайте файл переходной прошивки **`ax55v1_telnet_factory.bin`** из раздела [Releases](../../releases).

---

### Шаг 2: Разблокировка роутера через браузер
1. Подключите сетевой кабель от ПК в любой **жёлтый LAN-порт** роутера Archer AX55.
2. Откройте браузер и перейдите в админку TP-Link: [http://192.168.0.1](http://192.168.0.1) (или `192.168.1.1`, в зависимости от настроек).
3. Перейдите в раздел: **Дополнительные настройки** ➔ **Системные инструменты** ➔ **Обновление встроенного ПО**.
4. В блоке «Локальное обновление» выберите скачанный файл **`ax55v1_telnet_factory.bin`** и нажмите **Обновить**.
5. Дождитесь перезагрузки роутера (~2 минуты). **Поздравляем: скрытый Telnet-доступ открыт!**

---

### Шаг 3: Автоматическая прошивка OpenWrt
Запустите графическую утилиту прошивки:
* Дважды кликните по файлу **`gui.bat`** (или `run.bat` для работы в консоли).

В открывшемся окне:
1. Нажмите кнопку **«Проверить Telnet»** — индикатор подтвердит готовность роутера.
2. Нажмите **«Шаг 1: Скачать файлы OpenWrt»** — программа скачает официальные свежие сборки напрямую с серверов OpenWrt.
3. Нажмите **«Шаг 2: Прошить Factory Initramfs через Telnet»** — программа автоматически загрузит образ на роутер, переключит параметры загрузчика U-Boot и прошьёт загрузочное ядро. Роутер перезагрузится.
4. Подождите 40 секунд и нажмите **«Шаг 3: Завершить постоянную прошивку (Sysupgrade)»** — прошьётся постоянный образ OpenWrt в память роутера.

Готово! Роутер перезагрузится в постоянную систему **OpenWrt** по адресу **`http://192.168.1.1`**!

## 💻 Ручной метод (Для продвинутых пользователей)

Если вы предпочитаете выполнять все шаги вручную через терминал:

1. **Подключитесь к роутеру по Telnet:**
   ```bash
   telnet 192.168.0.1
   ```
2. **Проверьте разметку MTD-памяти:**
   ```sh
   cat /proc/mtd
   # Убедитесь в наличии mtd11: "rootfs"
   ```
3. **Настройте переменные U-Boot:**
   ```sh
   fw_setenv tp_boot_idx 0
   fw_setenv config_name config@mp03.3
   fw_printenv tp_boot_idx config_name
   ```
4. **Загрузите образ `openwrt-...-initramfs-factory.ubi` в `/tmp` и запишите его в `rootfs`:**
   ```sh
   wget http://192.168.0.2:8000/openwrt-qualcommax-ipq50xx-tplink_archer-ax55-v1-initramfs-factory.ubi -O /tmp/factory.ubi
   mtd erase rootfs && mtd write /tmp/factory.ubi rootfs
   sync && reboot
   ```
5. **После перезагрузки подключитесь по SSH к `192.168.1.1` и выполните финализацию:**
   ```sh
   ssh root@192.168.1.1
   wget http://192.168.1.2:8000/openwrt-qualcommax-ipq50xx-tplink_archer-ax55-v1-squashfs-sysupgrade.bin -O /tmp/sysupgrade.bin
   sysupgrade -n /tmp/sysupgrade.bin
   ```

## 🌐 Настройка веб-интерфейса LuCI и русского языка

Сборки OpenWrt Snapshot идут в минималистичном виде без веб-интерфейса. Чтобы установить красивую графическую админку:

1. Подключите кабель с интернетом в **синий WAN-порт** роутера.
2. Подключитесь по SSH к роутеру:
   ```bash
   ssh root@192.168.1.1
   ```
3. Выполните установку LuCI (OpenWrt использует пакетный менеджер `apk`):
   ```sh
   apk update
   apk add luci luci-i18n-base-ru
   /etc/init.d/uhttpd restart
   ```
4. Откройте в браузере **`http://192.168.1.1`** — перед вами полноценный русский веб-интерфейс LuCI!

## 📡 Бонус: Настройка бесшовной 802.11s Wi-Fi 6 Mesh-сети

Если вы используете Archer AX55 в паре со вторым роутером (например, на базе MediaTek MT7981B) для создания беспроводного моста:

### 1. Установка пакета Mesh:
```sh
apk del wpad-basic-mbedtls
apk add wpad-mesh-mbedtls
```

### 2. Важные нюансы Qualcomm ath11k:
* **Диапазон 2.4 ГГц:** В драйвере `ath11k` для региона `RU` заблокирован режим `HE` (Wi-Fi 6) на 2.4 ГГц. Чтобы точка доступа не падала с ошибкой `Failed to set beacon parameters`, в `/etc/config/wireless` укажите для радиомодуля 2.4 ГГц:
  ```uci
  set wireless.radio0.htmode='HT20'
  set wireless.radio0.channel='6'
  ```
* **Разделение каналов:** Главный роутер настройте на **Канал 1 (20 МГц)**, а сателлит AX55 — на **Канал 6 (20 МГц)**. Это исключит взаимные помехи на 2.4 ГГц.
* **Канал 5 ГГц:** Одинаковый для обоих роутеров (например, **Канал 36**, `HE80`, 80 МГц) для работы Mesh-транка.
* **Бесшовный роуминг:** Включите `ieee80211k='1'`, `ieee80211v='1'`, `bss_transition='1'` и `mobility_domain='4f57'`.

## 🔄 Откат на заводскую прошивку (Rollback)

Поскольку загрузчик U-Boot сохранил оригинальную структуру разделов TP-Link, возврат на заводскую прошивку прост:
1. Загрузитесь в консоль OpenWrt.
2. Переключите индекс загрузки обратно на резервный слот стока:
   ```sh
   fw_setenv tp_boot_idx 1
   reboot
   ```
3. Либо прошейте оригинальный образ TP-Link через TFTP-сервер (по стандартной процедуре восстановления TP-Link: зажатие кнопки Reset при включении с адресом сервера `192.168.0.66`).
